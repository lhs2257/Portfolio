HOW I WORK

요구사항과 처리 흐름 정의

사용자의 입력부터 결과 확인과 저장까지 이어지는 흐름을 정리합니다. 업무 규칙과 입력 조건, 완료 기준을 확인한 뒤 필요한 기능을 구현합니다.

AI와 서버의 역할 분리

내용 해석과 추정은 AI에 맡기고, 금액 계산과 데이터 검증처럼 정확성이 필요한 작업은 서버에서 처리합니다. 생성형 AI의 결과가 서비스 로직을 직접 결정하지 않도록 역할을 구분합니다.

단계별 오류 확인과 재검증

오류가 발생하면 입력 데이터, 모델 응답, 서버 처리와 화면 출력 중 어느 단계에서 문제가 생겼는지 로그로 확인합니다. 수정 후에는 동일한 조건을 다시 실행해 문제가 해결됐는지 검증합니다.

실패해도 이어지는 처리 방식 설계

AI 분석이나 자동 처리가 실패할 가능성을 고려해 사용자가 작업을 계속할 수 있는 대체 경로를 마련합니다. 자동 처리만으로 완료되지 않는 상황까지 서비스 흐름에 포함합니다.
